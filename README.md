# Informática Abood

Site institucional (front-end) para uma loja fictícia de informática —
projeto de estudo de HTML/CSS/JS, com catálogo de produtos e página de contato.

## Estrutura

```
InfoAbood/
├── index.html       # página inicial
├── produtos.html     # catálogo de produtos
├── contato.html      # formulário de contato
├── pag1.html          # página adicional
├── css/
├── js/                # carousel.js (carrossel de imagens) + main.js
└── img/
    ├── icones/        # ícones de contato/redes sociais
    ├── banners/        # banners da página inicial
    ├── produtos/       # fotos usadas no catálogo
    └── nao-utilizadas/  # imagens que estavam no projeto mas não são
                          # referenciadas em nenhuma página (mantidas
                          # aqui só pra não perder nada — pode apagar
                          # com segurança se não for usar)
```

## Tecnologias

- HTML5
- CSS3
- JavaScript (carrossel de imagens)

## Como rodar

É um site estático — basta abrir `index.html` no navegador, ou servir a
pasta com qualquer servidor local (ex: extensão "Live Server" do VS Code).
