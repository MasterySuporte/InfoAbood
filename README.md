# Informática Abood

Site institucional (front-end) para uma loja fictícia de informática —
projeto de estudo de HTML/CSS/JS, com catálogo de produtos e página de contato.

## Páginas

- `index.html` — página inicial
- `produtos.html` — catálogo de produtos
- `contato.html` — formulário de contato
- `pag1.html` — página adicional

## Tecnologias

- HTML5
- CSS3
- JavaScript (carrossel de imagens)

## Como rodar

É um site estático — basta abrir `index.html` no navegador, ou servir a
pasta com qualquer servidor local (ex: extensão "Live Server" do VS Code).
